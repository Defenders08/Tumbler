# Tumbler

Блоговая социальная сеть в эстетике Tumblr 2012 года: дашборд с композером семи типов постов, публичные блоги с настраиваемой темой, GIF как самостоятельный тип публикации.

**Статус:** MVP по ТЗ реализован полностью — этапы 0–10 (исследование, каркас, аккаунты/блоги, дизайн 2012, посты и медиа, социальные механики, поиск и Ask box, планировщик и уведомления, модерация и админ-панель, API и статистика, security-ревизия и деплой-документация). **80 автотестов проходят**, чистая установка и backup/restore проверены.

## Требования

- Node.js **22+** (проверено на 26.5), npm 10+.
- Никаких внешних сервисов: база — SQLite (better-sqlite3, WAL), медиа — локальные файлы.

## Быстрый старт

Одна команда из корня проекта:

```bash
npm ci && npm start
```

Сервер поднимется на <http://localhost:3000> и сам накатит миграции. Ручной вариант:

```bash
npm ci          # установка зависимостей по package-lock.json
npm run migrate # миграции SQLite (идемпотентны)
npm start       # запуск
```

Для разработки с автоперезапуском: `npm run dev`. Тесты: `npm test`.

## Переменные окружения

Скопируйте `.env.example` в `.env` и при необходимости отредактируйте. Всё запускается и без него.

| Переменная | Назначение |
|---|---|
| `NODE_ENV` | `development` / `production`. В production обязателен `SESSION_SECRET` |
| `PORT` | Порт HTTP (по умолчанию 3000) |
| `DATA_DIR` | Каталог данных: база, загрузки, dev-секрет (по умолчанию `./data`) |
| `DB_PATH`, `UPLOAD_DIR` | Явные пути к базе и медиа (по умолчанию внутри `DATA_DIR`) |
| `SESSION_SECRET` | Секрет сессий/CSRF. В production обязателен: `openssl rand -base64 48` |
| `ADMIN_EMAIL`, `ADMIN_PASSWORD` | Первая учётка администратора: создаётся при старте, если админа ещё нет |
| `DEFAULT_LOCALE` | Язык интерфейса для гостей (`ru`/`en`) |

В разработке секрет сессии автоматически сохраняется в `data/session-secret`, чтобы сессии переживали рестарты.

## Что уже работает

- **Аккаунты:** регистрация (email + пароль, argon2id), вход/выход, серверные сессии в SQLite, CSRF (double-submit), rate limiting входа и регистрации, seed администратора из env.
- **Блоги:** один блог на аккаунт с уникальным slug, настройки профиля, аватар, акцентный цвет заголовка, кастомный фон на всю страницу (затемнённый), перекраска интерфейса по оттенку фона — по картинке, своим цветом или с отключением (меняется в реальном времени), и соцсети в шапке блога: цветные кнопки со значком, подписью и ссылкой (до 8).
- **Посты — 7 типов:** текст (Markdown), фото (до 10 изображений), цитата, ссылка, аудио, видео и **GIF отдельным типом** (статичные GIF и GIF в фото-постах отклоняются с понятной ошибкой).
- **Медиа:** загрузка с проверкой фактического содержимого (magic bytes через file-type + sharp), лимиты из настроек, хранение вне БД через абстракцию хранилища (заменяема на S3), отдача через `/media/:key` с `nosniff`.
- **Черновики:** сохранение, список, редактирование, публикация из черновика.
- **NSFW 18+:** флаг на посте; гостям тело поста не отдаётся вовсе — только заглушка, согласие фиксируется cookie.
- **Поиск и теги:** FTS5 (unicode61 + префиксы — ищет по русским словоформам), страницы тегов, поиск постов/блогов/тегов с фильтром типа, поисковая строка в шапке.
- **Ask box:** вопросы блогу (лимит 500 знаков), анонимные вопросы (по желанию владельца, 5/час на IP), входящие с ответом постом, игнор/удаление.
- **Планировщик:** отложенная публикация по дате/времени (в часовом поясе пользователя) и очередь (пост раз в 30 минут); переживает рестарт сервера — состояние в SQLite; страница очереди с публикацией «сейчас» и отменой.
- **Уведомления:** подписка/лайк/реблог/комментарий/вопрос с антидубликатами, непрочитанный бейдж в шапке, отметка прочтения.
- **Модерация:** жалобы на посты/комментарии/блоги, баны пользователей (мгновенное завершение сессий), скрытие контента, журнал действий модераторов, лимиты загрузок и включатель регистрации в админке. Все проверки ролей — на сервере.
- **API и статистика:** документированный `/api/v1` (см. `docs/api.md`), счётчик просмотров с дедупликацией по visitor-cookie, статистика блога для владельца (`/stats`).
- **Лента:** вкладки «Общая лента» и «Подписки»; последняя активная запоминается в cookie на год и открывается при следующем заходе на дашборд.
- **Социальные механики:** подписки (toggle, лента подписок строго хронологическая), лайки (toggle через JSON API, активное состояние сердца), реблоги с добавленным текстом (цепочка авторов с вложенными цитатами, до 5 уровней + счётчик; удаление корня превращает содержимое реблога в заглушку «Исходный пост удалён»), комментарии (публичное чтение, добавление/удаление своих), счётчики активности, подписки в сайдбаре, кнопка подписки в панели блога со счётчиком подписчиков. Гостям действия ведут на вход.
- **Дизайн 2012:** палитра и размеры из оригинальных CSS той эпохи (см. `docs/research/`), адаптив (десктоп/планшет/мобильный с нижней навигацией), RU/EN интерфейс.

## Структура

```
src/
  server.js, app.js     # запуск и сборка приложения
  config.js             # env-конфигурация
  db/                   # SQLite-подключение (WAL), миграции, настройки
  modules/
    auth/               # регистрация, сессии, CSRF
    blogs/              # блоги, темы, аватар
    posts/              # 7 типов постов, черновики, теги, markdown
    media/              # storage-абстракция, валидация файлов, multer
    pages/              # дашборд, черновики, публичный блог, пермалинк
  views/                # liquidjs-шаблоны (layout, композер, карточка поста)
  public/               # CSS-токены 2012, ванильный JS, SVG-иконки
  locales/              # ru.json, en.json
migrations/             # SQL-миграции (применяются в транзакциях)
docs/                   # исследование Этапа 0 и архитектурные решения
tests/                  # node:test, 80 тестов (e2e через HTTP)
data/                   # база и загрузки (создаётся автоматически, не в Git)
```

## Известные ограничения

- Замена медиафайла при редактировании не поддерживается (нужно удалить пост и создать заново).
- Видео- и аудио-файлы отдаются как есть, без перекодирования; ссылки на внешние видео (YouTube и т.п.) не встраиваются.
- Пользовательский CSS блогов ещё не включён (CSP готов; включение — после MVP).
- Русский поиск находит словоформы через префиксы (без полноценного стемминга) — осознанное ограничение FTS5, зафиксировано в docs/research/risks.md.
- Создание постов через API — только через веб; API записи планируется после MVP (см. docs/api.md).
- Первый визит нового посетителя не считается во views (выдаётся visitor-cookie) — см. docs/api.md.
