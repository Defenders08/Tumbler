# Дизайн-спецификация Tumbler

**Статус:** исследование Этапа 0. Цель — эстетика веба Tumblr 2012 (осень 2012, веб-дашборд), не современный SaaS-минимализм.
**Основание:** docs/research/tumblr-2012.md. Пометки: [П-2012] — размеры/цвета из оригинальных CSS/спрайтов; [РЕШ] — проектное решение Tumbler; [Р] — реконструкция.

## 1. Принципы

- Плотная компоновка старого веба: контейнер 900px [П-2012], компактные отступы, мелкий служебный текст.
- Запрещено: огромные скруглённые карточки, чрезмерные градиенты, glassmorphism, теневые «плавающие» модалки, анимации ради анимаций.
- Разрешено (дух 2012): лёгкие тени, 1px-рамки, маленькие радиусы, градиент шапки, серые кнопки с обводкой, состояние hover с изменением прозрачности.
- Контраст и доступность не приносятся в жертву стилю: текст на тёмно-синих поверхностях — светлый #f5f8fa+; интерактив имеет focus-состояние.

## 3. Дашборд

### 3.1. Шапка [П-2012 + РЕШ]

- Высота 71px, фон: линейный градиент `#3a5a77 → #2c4762` (реконструкция) поверх базового #2c4762.
- Слева — логотип Tumbler: буква **t** в белой рамке-квадрате (свой SVG, отрисовка «по мотивам», не копия) + белая надпись «tumbler.» [РЕШ].
- Центр-лево: табы навигации (Дашборд / Поиск / Мой блог / Уведомления), белый текст 15px, hover #dde7f0, под активным табом «носик»-треугольник 12px цвета фона.
- Справа (зона 190px): иконки Home, Inbox-конверт с бейджем непрочитанных, шестерёнка (настройки), аватар 24×24 с меню аккаунта; кнопки «Войти» (тёмная с обводкой) и «Регистрация» (голубая) для гостей.
- Поиск в шапке: поле 38px, градиент #3b5974, иконка лупы, placeholder «Поиск Tumblr» / «Search Tumblr».

### 3.2. Сетка [П-2012]

Контейнер 900px: лента слева 625px, сайдбар справа 215px (белый текст на тёмном фоне, градиентный «хвост» вниз). Аватары постов выносятся влево за карточку (−85px), на экранах <1100px аватары прижимаются внутрь карточки [РЕШ].

Сайдбар (авторизованный): мини-профиль (аватар 64×64 квадратный, название блога, кнопка «Настроить») → «Подписки (N)» → «Черновики / Очередь» → «Радар» (случайный публичный пост — [РЕШ] замена проприетарному Radar). Гостевой: блок «Войдите, чтобы подписываться и лайкать».

### 3.3. Композер [П-2012 + РЕШ]

Белая карточка высотой 91px: слева аватар 64×64, справа — 7 кнопок-иконок по 75px с подписями 15px #575d69:

| Тип | Иконка (свой SVG в духе 2012) | Цвет иконки |
|---|---|---|
| Текст | «Aa» | тёмно-серый |
| Фото | фотоаппарат | красно-оранжевый |
| Цитата | кавычки | жёлто-оранжевый |
| Ссылка | цепь в зелёном круге | зелёный |
| Аудио | наушники | фиолетовый |
| Видео | кинокамера | тёмно-серый |
| GIF | рамка с надписью «GIF» | бирюзовый/тёплый жёлтый [РЕШ — цвет слота свободен, т.к. в 2012 слот занимал синий chat-пузырь] |

Открытие формы: карточка раскрывается вниз (не модалка — [РЕШ], ближе к духу 2012 и проще на мобильном); форма типа-специфичная, теги через запятую, кнопки «Опубликовать» (синяя), «Сохранить черновик» (серая), «Предпросмотр», расписание (ссылка «Параметры публикации»: отложенная дата/время, в очередь). GIF-форма: загрузка файла с анимированным предпросмотром, размер/лимиты видны сразу.

### 3.4. Карточка поста [П-2012]

- `padding: 15px 20px; background: #fff; border-bottom: 2px solid #bbb; border-radius: 10px; box-shadow: 0 1px 5px rgba(0,0,0,.46)`.
- Верх: аватар 64×64 (радиус 6px, вынесен влево) + имя блога bold + таймстамп 13px #a8b1ba; справа на hover — dogear-пермалинк 23×23.
- Реблог: строка источника «blogA реблогнул у blogB» с ссылками + суб-аватар 30×30; добавленный текст реблогера над цитатой оригинала; оригинал — в `blockquote` со светлой рамкой слева (по духу blockquote-цепочек 2012, максимум 2 уровня + «…ещё N» [РЕШ]).
- Медиа: max-width 500px; GIF анимируется всегда; NSFW-пост — обложка-занавес с кнопкой «Показать» (18+).
- Действия (строка справа над контентом, 13px bold): реблог 24×20, лайк-сердце 19×19 (активное — залитое красное), ответить/комментарий-облачко; opacity .65 → hover .9 → active 1; счётчик активности рядом: «12 лайков · 3 реблога · 5 комментариев» (компактный счётчик по ТЗ, кликабельный к списку).
- Тип-специфика отображения: цитата — крупный текст цитаты + «— источник»; ссылка — карточка с favicon-доменом, заголовком, описанием, превью-скрином; аудио — плеер с обложкой; видео — HTML5 video или embed; GIF — картинка + бейдж «GIF» в углу.

### 3.5. Комментарии [РЕШ — улучшение в духе 2012]

Блок под постом, свёрнутый по умолчанию («N комментариев»): строки в стиле notes 2012 — фон #e7eaec, 11px Lucida Grande, аватар 24×24 квадратный, имя bold, серый текст. Форма добавления: однострочный input + кнопка. Модерация автором поста: удалить/скрыть через меню «⋯».

### 3.6. Уведомления-«облачка» [П-2012]

В ленте над постами: плашки 464px, фон #455f78, рамка 1px #2a3f56, текст Lucida Grande 11px, аватар в рамке 33×33. Страница уведомлений: тот же стиль списком; непрочитанные — светлее фон + синяя точка; счётчик-бейдж в шапке.

## 4. Публичный блог

- Тонкая серая панель Tumbler сверху (аналог iframe-бара 2012 [П-2012]): логотип t, кнопка «Подписаться», счётчик подписчиков. [РЕШ: своя панель, не iframe]
- Шапка блога: аватар 128×128 (квадрат, радиус 6px), название, описание; фон — заливка/тайл из настроек темы.
- Контент: центрированная колонка 500px, посты той же карточной системы; подпись/теги/дата; пагинация «Предыдущие / Следующие» (классическая, не бесконечная — [РЕШ]).
- Сайдбар блога (опционально по теме): Archive (календарь/список месяцев), Likes (недавние лайки блога — опция), Ask box ссылка.
- **Темы и кастомизация [РЕШ]:** одна базовая тема «Redux-2012» + настраиваемые параметры: фон (цвет/тайл), цвета акцентов, шрифт из 3 разрешённых стеков, аватар, заголовок, описание, показ Ask box. Плюс «продвинутый» режим: пользовательский CSS.
- **Пользовательский CSS — правила безопасности:** применяется только к странице публичного блога через отдельный `<style>` с префиксом области видимости; санитизация: запрет `@import`, `url(javascript:…)`, `position: fixed` для чужих оверлеев не блокируем (осторожно), но страница отдаётся со строгим CSP (`script-src 'self'`) — CSS не может исполнить JS; системные экраны и админка пользовательский CSS не получают. Предпросмотр в настройках блога (iframe) и «Сбросить тему».

## 5. Экранные состояния

Каждый экран описывает: loading (скелетон серых плашек в стиле карточек, без спиннеров-прогрессбаров — дух 2012), empty («Здесь пока ничего нет» + иллюстрация-иконка), error (плашка с текстом + кнопка «Повторить»), disabled (opacity .5, cursor: not-allowed), focus (2px outline #5791bb со смещением 2px — доступность), hover/active по разделу 3.4.

Кнопки: классические прямоугольники с радиусом 4px и лёгким градиентом; primary — голубой #5791bb (hover #6aa5cf), success — зелёный #699d48 (follow), secondary — белая с 1px обводкой #bbb, danger — тёмно-красная. Пагинация: «‹ Новые | Номера страниц | Старые ›».

## 6. Адаптивность [РЕШ — реконструкция: мобильного дашборда 2012 не сохранилось]

- ≥1100px: полная сетка 900px, аватары вынесены за карточку.
- 900–1100px: аватары прижимаются внутрь карточки (в строке с именем).
- 640–900px: сайдбар уходит под ленту (или в выдвижное меню «☰»); лента 100%–32px.
- <640px: одноцветная шапка без градиента (высота 56px), поиск отдельной строкой, композер — 4+3 иконки в две строки, карточки без тени, медиа 100% ширины, действия крупнее (44px touch-target), нижняя панель навигации (Дашборд/Поиск/＋/Уведомления/Профиль).
- Горизонтальная прокрутка не допускается ни на одной ширине.

## 7. Иконки [РЕШ]

Полный набор — собственные SVG (24×24 сетка, стиль плоской пиктографии 2012, 1–2 цвета заливки): 7 типов постов (два состояния), home, конверт, шестерёнка, лупа, сердце (контур/залитое), реблог-стрелки, облако-комментарий, dogear-пермалинк, «⋯», warning 18+, теги, часы (расписание), черновик (карандаш), очередь (список). Никакие ассеты Tumblr (спрайты, логотип) в проект не включаются.

## 8. Открытые вопросы дизайна (не блокируют старт)

1. Точная кривая градиента шапки — реконструкция; финализируется на этапе 3 при визуальной сверке со скриншотами.
2. Цвет слота GIF-иконки композера — предложение (тёплый жёлтый) может измениться после первого прототипа.
3. Вид мобильной нижней навигации — авторская реконструкция в духе 2012.
