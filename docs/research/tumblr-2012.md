# Исследование: интерфейс Tumblr образца 2012 года

**Статус:** исследование Этапа 0, фактология для дизайн-спецификации.
**Дата:** 2026-11-08.
**Обозначения:** **[П]** — проверено источником (CSS/HTML/спрайты/скриншоты из Wayback Machine или публицистика со ссылкой), **[Р]** — реконструкция (экспертная оценка с указанием уверенности: выс./сред./низ.).

## 1. Методология и ограничения

Главный источник — Wayback Machine: в архиве сохранились **настоящие CSS-файлы дашборда Tumblr (сентябрь–октябрь 2012), PNG-спрайты иконок и промо-скриншоты**, которые были скачаны и разобраны напрямую. Это даёт точные hex-цвета и пиксельные размеры, а не догадки по памяти.

Ограничения:
- Залогиненный HTML дашборда в архиве **не сохранился** (краулер получал редирект на логин). Восстановление ведётся по: CSS дашборда, спрайтам, промо-скриншоту Tumblr и скриншоту Web Design Museum.
- Version Museum Tumblr не покрывает (проверено: страницы о Tumblr нет); заменён Web Design Museum + Wayback.
- Градиентная картинка шапки `background.png` из архива не скачалась — градиент помечен как реконструкция.
- Web Design Museum блокирует прямой fetch (403), использованы его архивные копии.

**Правило проекта:** скачанные ассеты (спрайты, логотип) — только визуальный референс. В код Tumbler они **не включаются**; все иконки рисуем самостоятельно (см. design-spec.md).

## 3. Каркас и шапка дашборда

Из `global.css` от 10.10.2012 [П]:
- Фон страницы: `body { background: #2c4762 url('/images/background.png') top repeat-x }` — база **#2C4762**, сверху градиентная полоса (картинка не скачалась, градиент — [Р], увер. низ./сред.: светлее сверху, ~#3a5a77 → #2C4762).
- Контейнер: `#container { width: 900px }`, шапка `#header { height: 71px }`.
- Логотип: белая рукописная надпись **«tumblr.»** слева (`margin: 14px 13px 0 15px`). Буква «t» в рамке — отдельный элемент (иконка приложения 2012 года) [П — косвенно, промо-скриншот].
- Навигация: `#nav { right: 190px; top: 19px }`, пункты `.nav_item { font-size: 15px; color: #fff }`, hover `#dde7f0`. Правые 190px шапки — под аккаунт-меню.
- Поиск: `#search_form { height: 38px }`, градиент поля светлее фона, упор **#3B5974**. Под активным табом — треугольник-«носик» (`selection_nipple`, `border-bottom: 12px solid #2c4762`).
- Табы шапки: `#tabs_container { max-width: 475px }`.

Скриншот Web Design Museum 2012 [П]: справа вверху кнопки «Log in» (тёмная с обводкой) и «Sign up» (голубая заливка); правая колонка — поле «Search Tumblr» с лупой, список трекаемых тегов, блоки Explore/Spotlight.

Иконки справа в шапке (Home-домик, конверт Inbox, шестерёнка) — [Р], увер. сред.; конверт присутствует в master-спрайте 2012 [П].

## 5. Композер: 7 типов постов и иконки

Оригинальный Tumblr 2012 имел типы **Text, Photo, Quote, Link, Chat, Audio, Video** [П — подписи на промо-скриншоте, классы `#new_post_label_*` в CSS].

Спрайт `post_icons.png` (513×190, Wayback 20.03.2012) просмотрен визуально [П]. Иконки (шаг 75px, каждая в двух состояниях обычное/hover):
- **Text** — серо-чёрное «Aa»;
- **Photo** — красно-оранжевый фотоаппарат;
- **Quote** — жёлто-оранжевые кавычки;
- **Link** — зелёный круг со звеном цепи;
- **Chat** — синий пузырь с надписью «hi!»;
- **Audio** — фиолетовые наушники;
- **Video** — тёмно-серая кинокамера с двумя катушками.

Подписи под иконками: `.new_post_label { width: 75px; padding-top: 61px; color: #575d69; font-size: 15px }` [П].

«Answer» как 8-й тип в композере появился в январе 2013 [Р, увер. сред.] — в 2012 ответ на ask публиковался как обычный пост и отображался в notes (`li.answer` [П]).

## 6. Действия над постом, notes, лайки и реблоги

Из `dashboard.css` 30.10.2012 [П]:
- Кнопки-иконки в строке `.post_controls` в правом верхнем углу карточки (рядом счётчик notes): `font-size: 13px; bold; color: #a8b1ba`, ссылки `#818b98`, базовая opacity .65 → hover .9 → active 1.
- Like: 19×19 сердце из master-спрайта; активное состояние `.already_like` — **залитое красное сердце**, opacity 1.
- Reblog: 24×20; состояние «уже сделан» — залитый вариант.
- Reply: иконка-облачко.
- Пермалинк — «загнутый уголок» (`dogear.png`, 23×23) в правом верхнем углу, виден на hover.
- Список notes: `ol.notes li { background: #e7eaec; font: 11px 'Lucida Grande'; bold; color: #567; border-radius: 5px }`, у лайков/реблогов — свои иконки; счётчик «N notes» серым бейджем.

Поведение 2012 [П/Р]:
- Лайки и реблоги отображались в списке notes; «комментариев» в современном смысле не существовало — reply был текстовой припиской в notes, а текст при реблоге добавлялся в **вложенную цепочку `<blockquote>`** (каждый реблог — уровень вложенности) [П: engineering.tumblr.com «How Reblogs Work», support-пост о «crazy-long reblog chains»].
- Кнопка reblog открывала форму нового поста с предзаполненной цитатой оригинала; контент оригинала редактировать было нельзя, практиковалась «обрезка» цепочки [Р, увер. выс.].
- В ленте над постами шли тёмно-синие «облачка»-уведомления о лайках/реблогах/подписках (`.notification`) [П].

## 8. Типографика

- База: `body { font: normal 14px/1.4 "Helvetica Neue", Helvetica, Arial, sans-serif; color: #444 }` [П].
- Вторичный стек: `"Lucida Grande", "Lucida Sans Unicode", sans-serif` — notes, уведомления, сайдбар [П].
- Размеры в темах блогов 2012: 10, 11, 12, 13, 16, 24, 36px [П]; служебные подписи 13px bold; notes 11px; заголовки промо 26px.
- Для публичных блогов большинство тем эпохи использовало тот же Helvetica Neue/Arial; текст 12–14px, заголовки 16–22px [Р, увер. сред.].

## 9. Публичный блог 2012

Реальные примеры из Wayback [П]:
- **staff.tumblr.com** (02.01.2013): шапка с названием и слоганом, сайдбар (Archive, теги), одноколоночные посты с датой и счётчиком лайков, футер «© 2007–2012 Tumblr, Inc.».
- **marco.org** (31.12.2012): одна колонка, шапка «Marco.org • About» + строка био, архив по месяцам в сайдбаре, заголовки-ссылки, пермалинк «∞», RSS.
- Тонкая серая **панель Tumblr поверх блогов**: iframe 330×25px сверху (follow/dashboard) [П из HTML ask-страницы].
- Ask-страница блога `/ask`: заголовок «<Имя>: Ask a question», форма — iframe высотой 190px [П].

Типовая структура блога эпохи [Р, увер. выс. для ширины]: центрированная колонка ~500px (фотопосты 400/500px — стандарт `{Photo-500}` тем), шапка с аватаром 64–128px, заголовок и описание, боковая колонка (Following/Likes/Archive), фон — заливка или тайловая картинка из Customize. Платные темы существовали («Fluid 2» PixelUnion $49 [П]). Популярные темы 2011: The Minimalist, Inspire Well [П: staff-пост]; дефолты эпохи: Redux, Retina, Optimus, Effect, Field Notes [Р, увер. сред.].

## 10. Ask box

- Появился в янв.–февр. 2010 [П: staff-пост «Now testing: Replies» 16.02.2010, TechCrunch 16.02.2010].
- Форма вопроса (архив ask_form): `<textarea maxlength="500">` — **лимит 500 символов**; отправка только залогиненным, есть скрытый form_key (CSRF) [П].
- **Анонимные вопросы**: включаются владельцем блога; лимит для анонов ~5 вопросов/час; анонимный ask можно ответить **только публично** [П: справка Tumblr].
- Вид бокса 2012 [Р, увер. сред.]: белый бокс, заголовок «Ask me anything» (настраиваемый), textarea с плейсхолдером, кнопки Ask (синяя) / Cancel, чекбокс «Ask anonymously» при включённой анонимности, для анонов — CAPTCHA.

## 11. Отличия модели ТЗ от оригинала 2012

ТЗ фиксирует решения, отличающиеся от оригинала. Исследование подтверждает: это осознанные «небольшие улучшения» — реализуем в эстетике 2012:

| Механика | Tumblr 2012 | Tumbler (по ТЗ) |
|---|---|---|
| 7 типов постов | text, photo, quote, **chat**, audio, video | text, photo, quote, link, audio, video, **GIF** (отдельный тип вместо chat) |
| Комментарии | reply-приписки в notes + blockquote-цепочки реблогов | полноценные комментарии (стиль — по мотивам notes/replies) |
| Notes | единый список лайков/реблогов/replies | **не реализуем как отдельную механику** (по ТЗ); компактный счётчик активности (лайки/реблоги/комментарии) |
| GIF | фильтр по типу поста, лимит 1MB | самостоятельный тип со своей кнопкой/формой/превью |

Анонимные Ask-вопросы: по результатам исследования **рекомендуется реализовать** (владелец включает опцию; аноним ограничен rate-limit'ом; ответ только публичный) — решение делегировано исследованию пунктом 5.6 ТЗ, зафиксировано здесь и в decisions.md.
