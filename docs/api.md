# Tumbler API v1

Базовый адрес: `/api/v1`. Формат ответов — JSON.

- **Чтение публичных данных** — без авторизации.
- **Приватные данные** (`/me`, `/notifications`) и действия (лайк, подписка, реблог, комментарий) — по **сессионной cookie** `tumbler.sid` (обычная авторизация сайта) + CSRF-токен для мутирующих запросов.

## Формат ответов

Успех:

```json
{ "data": { ... }, "meta": { "page": 1, "perPage": 10, "total": 42, "pages": 5 } }
```

Ошибка:

```json
{ "error": { "code": "not_found", "message": "Post not found" } }
```

Коды ошибок: `401 need_login` (нет/просрочена сессия), `403` (CSRF/права), `404 not_found`, `429` (rate limit).

## Чтение

| Метод и путь | Описание |
|---|---|
| `GET /api/v1/posts?page=&limit=&type=` | Публичные посты всех блогов, строго хронологически. `type` — один из `text,photo,quote,link,audio,video,gif`. `limit` ≤ 50 |
| `GET /api/v1/posts/:id` | Пост + счётчик просмотров |
| `GET /api/v1/blogs` | Список блогов (последние 50) |
| `GET /api/v1/blogs/:slug` | Блог: описание, тема, подписчики, число постов |
| `GET /api/v1/blogs/:slug/posts?page=&limit=&type=` | Опубликованные посты блога |
| `GET /api/v1/blogs/:slug/stats` | Публичные агрегаты блога (посты, лайки, реблоги, комментарии, просмотры, подписчики) |
| `GET /api/v1/tags/:name?page=&limit=` | Посты по тегу |
| `GET /api/v1/search?q=&type=` | Поиск одним запросом: посты (FTS, до 20), блоги, теги |

Пример:

```bash
curl 'http://localhost:3000/api/v1/posts?limit=5&type=gif'
```

```json
{
  "data": [
    {
      "id": 12,
      "type": "gif",
      "title": null,
      "bodyHtml": "<p>Анимация!</p>",
      "tags": ["анимация"],
      "blog": { "slug": "boris", "title": "Мир Бориса" },
      "counts": { "likes": 3, "reblogs": 1, "comments": 0 },
      "publishedAt": "2026-11-08T01:16:00.000Z",
      "url": "/boris/12"
    }
  ],
  "meta": { "page": 1, "perPage": 5, "total": 1, "pages": 1 }
}
```

## С авторизацией (сессионная cookie)

| Метод и путь | Описание |
|---|---|
| `GET /api/v1/me` | Профиль аккаунта и блога, число непрочитанных уведомлений |
| `GET /api/v1/notifications` | Последние 50 уведомлений + `meta.unread` |

Пример:

```bash
curl -b cookies.txt http://localhost:3000/api/v1/me
```

## Действия (лайк, подписка, реблог, комментарии, Ask)

Мутирующие endpoints живут на `/api` (без версии) и требуют:

- cookie сессии;
- CSRF-токен в заголовке `x-csrf-token` (значение — из `<meta name="csrf-token">` любой страницы сайта под той же сессией).

| Метод и путь | Тело | Действие |
|---|---|---|
| `POST /api/posts/:id/like` | — | Toggle лайка → `{ liked, likeCount }` |
| `POST /api/blogs/:slug/follow` | — | Toggle подписки → `{ following, followerCount }` |
| `POST /posts/:id/reblog` | форма: `body`, `tags`, `back`, `_csrf` | Реблог с текстом (PRG-редирект) |
| `POST /posts/:id/comments` | форма: `body`, `back`, `_csrf` | Комментарий |
| `POST /:slug/ask` | форма: `question`, `anonymous?`, `_csrf` | Вопрос блогу (анонимно — если включено владельцем; лимит 5/час на IP) |

Ограничения частоты: вход 10/15 мин, регистрация 10/час, вопросы 5/час (анонимно), жалобы 10/час.

## Что не входит в v1 (осознанные ограничения)

- Запись постов через API (создание/редактирование) — только через веб-интерфейс; API записи постов планируется после MVP (чтобы не дублировать multipart-валидацию вне браузера).
- Модерация через API — только админ-панель.
- Токены доступа (API-ключи) — не реализованы; авторизация исключительно сессионная.

## Сбор данных (ТЗ 7.5)

Просмотры: на странице поста фиксируется один просмотр от посетителя (анонимный cookie-идентификатор) в сутки. Cookie выдаётся при первом заходе, поэтому самый первый визит нового посетителя не считается (со всех последующих страниц — считается). Никаких сторонних счётчиков и персональных данных сверх необходимого.
